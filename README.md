# Landing estática · Entrenamiento Efecto Polvo

Esta versión solo usa HTML y CSS. No requiere instalación ni compilación.

## Publicar en Vercel

1. Crea un repositorio nuevo en GitHub y sube **el contenido de esta carpeta**.
2. En Vercel selecciona **Add New > Project**.
3. Importa el repositorio.
4. En **Framework Preset**, selecciona **Other**.
5. Deja vacíos **Build Command** y **Output Directory**.
6. Pulsa **Deploy**.

El archivo principal es `index.html`.
